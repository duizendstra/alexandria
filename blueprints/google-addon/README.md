# Google Workspace Add-on Blueprints

Golden scaffolding templates for building Google Workspace Add-ons across two progression levels:

## Available Blueprints

| Directory | Level | Technology | Description |
|---|---|---|---|
| [`appsscript/`](appsscript/) | Level 1 | Google Apps Script (`CardService`) | Zero-friction, zero-setup prototype for Google Calendar time tracking powered by free Gemini Flash. |
| [`go/`](go/) | Level 2 | Go + Cloud Run (`ko`) | Enterprise-grade HTTP Alternate Runtime microservice using Alexandria's SRE Go stack (`go/platform/web`, `go/slog-gcp`). |
